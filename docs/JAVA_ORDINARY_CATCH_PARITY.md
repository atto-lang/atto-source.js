# Bounded typed ordinary catch

Java #1704 establishes ordinary catch versus raise/panic separation. Program-v2 now admits terminal braced try/catch in explicitly typed nonvoid functions. Protected body and handler must each terminate; normal continuation outside the try, general Error object use and defer/recover are deliberately not implemented. The catch binding has a compiler-checked distinct scope and permits only ordinary rethrow, preserving the caught object rather than creating a replacement. Catch and trap share the private ordinary guest classifier; host faults, raise, panic and unwrap panic remain outside ordinary catch. Core Error construction now fails if a declaration shadows the prelude identity. No actor supervisor routing, user-defined marker hierarchy, ownership destruction, or native AOT/zero-GC claim. 31 scoped isolated V8 checks executed before commit, Node ESM regressions added.
