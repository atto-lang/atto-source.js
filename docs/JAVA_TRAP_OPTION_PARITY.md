# Bounded Option-preserving trap

The Java-first contract requires trap(Option<T>) to yield Result<Option<T>,Error>, not Option<T> and not a flattened Result<T,Error>. In this executable slice Option<int> is preserved as the Ok payload, including None; existing typed Result is passed through, including a nested local trap. Distinct trapOptionResult typed IR slots and methods retain payload type across nested captures and unwrap; no public arbitrary Result/Error ABI is invented. Ordinary arithmetic errors are caught; unwrap panic propagates. 23 isolated V8 source-to-validated-IR-to-executed-artifact checks passed. Node ESM regressions added. Arbitrary generic Option/Result, full typed effects, async trap, ownership/drop and native AOT remain outstanding. This host-managed ESM tagged representation is not a zero-GC guest ABI.
